# Codex 일차별 작업 절차

이 문서는 사용자가 `N일차 시작`, `N일차 마무리`, `N일차 시작하고 마무리까지`처럼 요청할 때 적용한다.

## 요청 해석

- `N일차 시작` 또는 `N일차 시작하고 마무리까지`는 조사부터 구현, 검증, worklog 작성, 최종 보고까지 모두 수행한다.
- `N일차 마무리`는 현재 작업 트리의 부분 작업을 먼저 파악하고 남은 구현, 테스트, 문서화, 검증을 완료한다.
- 같은 일차 요청이 대화 중단 후 다시 들어오면 처음부터 다시 만들지 않는다. 현재 변경과 worklog를 확인하고 이어서 완료한다.
- 위험한 추측이 필요하지 않다면 별도 계획 승인 없이 작업을 진행한다.

## 시작 점검

1. 현재 브랜치와 `git status`를 확인한다.
2. 최근 커밋과 이전 일차 worklog를 확인한다.
3. 이전 일차 변경이 `main`에 병합되었는지 확인한다.
4. 작업 트리의 기존 변경은 사용자 작업으로 간주하고 보존한다.
5. 기존 변경을 되돌리거나 관련 없는 파일을 정리하지 않는다.
6. 최근 작업 흐름과 현재 코드에서 다음으로 자연스러운 작은 범위를 선정한다.

## 구현 원칙

- 저장소의 기존 패턴, 공통 컴포넌트, 타입과 테스트 방식을 우선한다.
- 요청 범위에 필요한 코드만 수정하고 관련 없는 리팩터링은 하지 않는다.
- 구현과 함께 대상 단위 테스트와 필요한 앱 회귀 테스트를 추가하거나 수정한다.
- 사용자에게 노출되는 문구가 변경되면 영문과 한글 번역을 함께 수정한다.
- 번역 변경이 필요하지 않으면 최종 보고에 그 사실을 명시한다.
- 파일 수정 전에는 어떤 변경을 할지 사용자에게 짧게 알린다.

## Worklog

작업을 마무리할 때 다음 두 파일을 모두 작성한다.

- `worklog/day-N-summary.ko.md`
- `worklog/day-N-summary.md`

각 worklog에는 다음 내용을 포함한다.

1. 목표
2. 완료한 작업
3. 변경 파일
4. 실제로 성공한 검증 명령
5. 제안 브랜치명
6. 제안 커밋 메시지

한국어와 영문 worklog의 작업 내용과 검증 목록이 서로 일치해야 한다. 제안 커밋 메시지는 두 문서 모두 같은 한글 메시지를 사용한다.

## 검증

변경 범위에 맞춰 다음 검증을 수행한다.

1. 변경된 컴포넌트 또는 모듈의 대상 테스트
2. 관련 웹 앱 회귀 테스트
3. `pnpm run format:check`
4. `pnpm run lint`
5. 공통 UI 변경 시 `pnpm -F @shared-ui/core storybook:build`
6. `pnpm run build:web`
7. `git diff --check`
8. 제안 커밋 제목의 `commitlint` 검사

- 검사 실패가 작업 변경에서 발생했다면 수정한 뒤 다시 실행한다.
- 기존 경고와 실제 실패를 구분하고 최종 보고에 남긴다.
- worklog에는 실제로 성공한 검증만 완료 상태로 기록한다.

## Git 규칙

- 사용자가 별도로 명시하지 않는 한 `git add`, `git commit`, `git push`를 실행하지 않는다.
- 이미 스테이징된 사용자 변경을 unstaged 상태로 되돌리지 않는다.
- 제안 브랜치가 로컬 또는 원격에 이미 존재하는지 확인한다.
- 브랜치명은 `type/scope-short-description` 형식을 사용한다.
- 브랜치명은 저장소의 `AGENTS.md`에 정의된 scope와 명명 규칙을 따른다.
- 커밋 type과 선택적 scope는 영어로 작성한다.
- 커밋 제목의 콜론 뒤와 본문은 한글로 작성한다.

## 최종 보고

최종 응답에는 다음 내용을 포함한다.

1. 해당 일차 완료 안내와 작업 목적
2. 주요 변경 내용
3. 클릭 가능한 절대 경로의 변경 파일 목록
4. 테스트, 포맷, 린트, 빌드와 diff 검사 결과
5. 번역 변경 여부
6. 실패가 아닌 기존 경고
7. 최종 `git status`
8. Git add, commit, push 실행 여부
9. 중복 여부를 확인한 제안 브랜치명
10. 한글 제목과 본문으로 된 제안 커밋 메시지

브랜치명과 커밋 메시지는 각각 복사하기 쉬운 별도 코드 블록으로 제공한다.
