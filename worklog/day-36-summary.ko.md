# 36일차 작업 정리

## 작업 내용
- `ShowcasePage`에 남아 있던 옵션 라벨과 설명 문구를 i18n으로 옮겼습니다.
- 페이지 내부의 하드코딩된 쇼케이스 옵션 배열을 i18n 기반 helper 함수로 교체했습니다.
- 언어 전환 시 옵션 라벨까지 바뀌는지 `/showcase` 테스트를 보강했습니다.

## 의미
- 쇼케이스 라우트도 페이지 본문뿐 아니라 폼 옵션 라벨까지 같은 다국어 기준을 따르게 됐습니다.
- 쇼케이스 페이지에 남아 있던 영문 하드코딩 옵션 문자열을 제거했습니다.
- 앞으로 locale 메시지가 바뀌어도 같은 구조로 유지보수하기 쉬워졌습니다.
